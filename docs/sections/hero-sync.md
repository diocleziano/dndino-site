# Connecting DnDino Hero: a guide for the DM

Receive players' character sheets into your adventure and manage supported game values from your Mac. The connection is local and does not require an external server.

For phone and tablet instructions, see the [Hero player's guide](../companion/dndino-sync.md).

!!! info "Availability of new features"
    Update both apps to versions that support the new connection. Sheet transfer, chat and Live are available on **iOS/iPadOS 17 or later**. If a device was paired only with the old connection, pair it once without a code. Devices already paired with the new system stay paired after an app update.

## First pairing

1. Open the adventure in DnDino. Open **Hero** in the bottom bar and turn on **Hero connection**. You do not need to start a live adventure session.
2. Ask the player to select the right sheet in Hero and join the same local network. Allow local network access when prompted.
3. The player opens **Settings → DnDino Connection**, turns on the connection, taps **Find DnDino** and selects your Mac by name.
4. In the **Hero** panel, choose **Pair** for the request. Check the device, then select the adventure and an existing player character or import a new one. Pairing with an existing character preserves its history.
5. To sync gameplay values, select **Enable Live after pairing**, or turn Live on later in the panel. The first time Live is enabled, DnDino requests the sheet from Hero automatically.

## Sheet, Live and chat

- The sheet request button next to chat imports the full sheet even when Live is off. It updates the player character during an ongoing combat without restarting the encounter. The player can also send it from Hero.
- Only the GM decides which devices use Live. Live updates HP, temporary HP, AC, conditions, Heroic Inspiration, class resources and spell slots in and out of combat. Fixed class progressions remain read-only.
- Chat is private. When a message arrives with the chat closed, the bottom bar shows a shortcut with an unread badge. Click to open the chat; reading it clears the badge.

## Disconnecting and revoking access

The panel lists online devices first. **Disconnected · Live authorized** means the device is offline but Live will resume when it returns. You can keep managing the character on the Mac. Reconnecting delivers queued updates without reimporting the sheet or opening a general comparison.

From the device menu you can test the connection, disconnect it, or revoke access to remove the pairing and queued updates. Revoking access does not delete the imported sheet. A new request is needed to pair again.

If the Mac does not appear, check that DnDino is listening, both devices are on the same local network, and Hero has **Local Network** permission.
