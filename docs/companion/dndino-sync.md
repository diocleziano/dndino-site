# Connecting to DnDino: a player's guide

Use DnDino Hero on iPhone or iPad to send your sheet to the DM and, when enabled, share game values during play. Hero remains usable without a connection.

The DM's instructions are in the [DnDino guide](../sections/hero-sync.md).

!!! info "Versions and availability"
    Update both apps to versions that support the new connection. Sheet transfer, chat and Live are available on **iOS/iPadOS 17 or later**. If a device was paired only with the old connection, pair it once without a code. Devices already paired with the new system stay paired after an app update.

## First pairing

1. Select the character you want to play in Hero.
2. Join the same local network on both devices and allow local network access when prompted.
3. Ask the GM to turn on **Hero connection** from the bottom bar in DnDino.
4. In Hero, open **Settings → DnDino Connection**, turn on the connection, tap **Find DnDino** and select the GM’s Mac by name.
5. Wait for the GM’s approval. There is no code or second confirmation. If the GM enables Live, Hero sends the first sheet automatically.

## Sheet, Live and chat

- **Send sheet to GM** transfers the full sheet, including gameplay values, even with Live off. The GM can also request it for an already paired character. Use the full sheet for level changes or other structural updates.
- Only the GM enables Live; Hero displays its status. HP, temporary HP, AC, conditions, Heroic Inspiration, class resources and spell slots can update during combat too. Hero shows combat start and end alerts and rests triggered by the GM.
- Open **Chat** in the connection panel to message the GM privately.

## If the connection drops

When you return to the app, Hero can reconnect without a new approval unless access was revoked. If Live was authorized, it resumes and queued updates are delivered without duplicates. A normal reconnection does not send the full sheet again. If both sides changed the same value offline, an outdated change may be rejected and Hero will match the value accepted by the GM.

If the Mac does not appear, check that DnDino is listening, both devices are on the same local network, and Hero has **Local Network** permission.
